# AI Conversation Helper — MVP TODO

## Current MVP (browser-only)
- [x] Responsive conversation-coaching interface
- [x] Paste chat text and upload screenshot
- [x] Browser-side OCR for PNG/JPG/WEBP screenshots
- [x] Transparent text-pattern cues and multiple possible interpretations
- [x] Reply options based on user-selected goal and tone
- [x] Editable replies and copy-to-clipboard
- [x] No account, no automatic sending, no server-side storage
- [x] Remove unsupported fake confidence scores and simulated real-time behavioral analysis
- [x] Clear limitations: this is heuristic assistance, not mind-reading or a connected generative AI model

## Next before calling it an AI-powered production release
- [ ] Add a backend endpoint for a real language model; never expose provider secrets in frontend code
- [ ] Validate request sizes, rate limits, timeouts, errors, and abuse controls
- [ ] Add clear consent and retention controls before any server-side processing
- [ ] Add tests for parsing, interpretation safeguards, reply generation, and OCR errors
- [ ] Test on mobile browsers and screen readers
- [ ] Add deployment checks and document environment variables
- [ ] Conduct opt-in usability testing and measure whether replies are useful

## Known limitations
- Current analysis is rule-based and can miss sarcasm, slang, context, and language variation.
- OCR quality depends on screenshot clarity and language; extracted text should be checked.
- The app does not detect facial expressions, body language, vocal tone, attraction, or hidden intent.
- Replies are templates selected by context rules, not generated by an LLM.
